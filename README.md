# Betano Companion

Aplicación Android personal para llevar una sesión de casino con criterio: carga manual de juego, RTP publicado, volatilidad, importe apostado y saldo. Muestra una burbuja flotante opcional encima de otras apps con el estado de la sesión.

## Importante

No predice giros, no detecta "juegos calientes", no lee ni controla Betano, no realiza apuestas y no elude restricciones. El RTP es una media teórica de muchas jugadas, no una garantía para una sesión.

## Cómo abrirla y generar el APK

1. Instalá Android Studio en una PC.
2. Elegí **Open** y seleccioná esta carpeta (`BetanoCompanion`).
3. Esperá a que termine la sincronización de Gradle.
4. Para probarla: conectá el teléfono por USB y presioná Run.
5. Para crear el instalador: **Build > Build APK(s)**. El APK queda dentro de `app/build/outputs/apk/debug/`.

Al activar la burbuja, Android abrirá el permiso especial “Mostrar sobre otras apps”. Elegí Betano Companion y habilitalo. La burbuja sólo muestra datos que cargaste vos.
